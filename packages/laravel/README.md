# @workersphp/laravel

The Laravel adapter for [Workers PHP](https://workersphp.dev): the dispatch
scripts that run HTTP requests, queue payloads and scheduled work through a
Laravel app inside a Cloudflare Workers isolate, plus the pack/bake build
tooling (secret-free app zips, Blade and config caches baked at deploy time,
Livewire asset conventions).

```js
import { createLaravelWorker } from '@workersphp/laravel';
import loader from '@workersphp/php-wasm-jspi/php8.5-web.mjs';
import wasm from '@workersphp/php-wasm-jspi/php8.5-web.mjs.wasm';

export default createLaravelWorker({ loader, wasm });
```

Pairs with the composer package `workersphp/laravel-bridge` (the in-app
drivers for D1, KV, Durable Object cache/locks, R2, Queues, broadcasting and
mail). Most deployments are generated by `@workersphp/cli` rather than
written by hand. Docs: https://github.com/workersphp/core
